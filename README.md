# 🎂 Happy Birthday — A Cinematic Birthday Surprise

> An interactive cinematic birthday surprise page — balloons, music and a hidden surprise for someone special.

**🔴 Live demo:** https://erionnezha.github.io/Happy-Birthday/

## 🎉 What it does

- Animated birthday scene with floating balloons 🎈
- Background music via `<audio>`
- Click through the experience to reveal the **surprise**
- All-in-one single `index.html` — no dependencies

## ▶️ Run locally

Open `index.html` in any browser.
