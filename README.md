# 🎂 Happy Birthday — A Cinematic Birthday Surprise

Created by **Erion Nezha**

> An interactive cinematic birthday surprise page — balloons, music and a hidden surprise for someone special. Fully in Albanian.

**🔴 Live demo:** https://erionnezha.github.io/Happy-Birthday/

## 🎉 What it does

- Animated birthday scene with floating balloons 🎈
- Synthesized "Happy Birthday" music via Web Audio API (music-box style + waltz accompaniment) — loops when you press **🎵 Luaj Muzikën**, no external audio file needed
- Floating 🔊/🔇 button to mute/unmute the music
- Click through the experience step by step to reveal the **surprise**
- All-in-one single `index.html` — no dependencies

## ▶️ Run locally

Open `index.html` in any browser.
